# LocalShop PWA

Aplicación Web Progresiva con Spring Boot, Thymeleaf (SSR), Spring Data JPA,
Service Worker y Geolocalización.

## Autores
- Vitaliano Cordova
- Sergio Ramos
- Jesús Rodriguez
- Daniel Peregrino
- Juan Gonzalez
- Jesus Morales

## Tecnologías
- Java 17
- Spring Boot 3.x (Web, Data JPA, Thymeleaf, Lombok)
- H2 Database
- Bootstrap 5
- Service Worker / Web App Manifest
- Geolocation API

## Requisitos previos
- JDK 17 o superior
- Maven 3.8+
- Google Chrome

## Ejecución local
1. Clonar el repositorio:
   git clone [(https://github.com/VITA110/localshop-pwa)]
   cd localshop-pwa
2. Ejecutar:
   mvn spring-boot:run
3. Abrir en el navegador: http://localhost:8080
